# viral-storytelling

Claude Code skill with a storytelling method for animated shorts and long-form videos: scripts built in beats (first event, failure, fix, retest), one visible action per line, script-to-scene anchors, facts from primary sources, and pacing that scales from 60-second shorts to 10-minute stories.

## Install

```bash
git clone https://github.com/pedropimenta/viral-storytelling.git ~/.claude/skills/viral-storytelling
```

On Windows the folder is `%USERPROFILE%\.claude\skills\viral-storytelling`. Claude Code loads it automatically; ask for a script, hook, beat sheet, storyboard or script review and the skill is used.

## What's inside

| Path | Content |
|---|---|
| `SKILL.md` | The core rule, format picker and 8-step workflow |
| `references/beats.md` | Explainer and true-story arcs, hooks, open loops, sentence rules |
| `references/short-form.md` | 45–100 s vertical structure and rhythm |
| `references/long-form.md` | 8–12 min block map, rhythm per block, 10 s scenes, documentary look, continuity bible |
| `references/script-to-scene.md` | Anchors, direction table, camera grammar, hard cuts, AI generation hygiene |
| `references/facts.md` | Sourcing rules and limits of representation |
| `references/review-checklist.md` | Story, picture, sound and delivery checks |
| `templates/` | Brief, script, direction, facts and storyboard scene templates |
| `examples/` | An explainer short and a 10-minute true story |
